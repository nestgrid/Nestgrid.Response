# Architecture

Architecture artefacts define the technical direction for the v0.7.0 EOS retrofit of Nestgrid.Response.

The existing v0.6.0 implementation is the baseline for review. Architecture approval is separate from the implementation baseline and from approval to begin Engineering.

1. [Architecture Recommendation](Architecture%20Recommendation.md)

6. [Architecture Investigation - OpenAPI Metadata Integration](Architecture%20Investigation%20-%20OpenAPI%20Metadata%20Integration.md)

The Architecture Pack and related decision records are the approved basis for Engineering handover. Conditional release items remain governed by the downstream Security, Quality and Platform gates.
