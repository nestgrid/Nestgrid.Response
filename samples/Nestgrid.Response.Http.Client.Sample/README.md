# Nestgrid.Response.Http.Client sample

This sample demonstrates two reusable consumer scenarios: a licence-service response using `FullResult`, and a Portal-to-Finance response using `ValueOnly`. Both use a normal `HttpClient` pipeline and the client reader; neither scenario adds consumer-specific infrastructure to the package.

Run it from the repository root:

```bash
dotnet run --project samples/Nestgrid.Response.Http.Client.Sample
```
