# Samples

The sample applications show the smallest useful ways to apply Nestgrid.Response packages.

## Purpose

Samples should be realistic enough to copy patterns from, but small enough to inspect quickly.

## Samples

| Sample | Demonstrates |
|---|---|
| [Nestgrid.Response.Sample](Nestgrid.Response.Sample/README.md) | Core result factories, `Map()`, and `Match()`. |
| [Nestgrid.Response.Extensions.Validation.Sample](Nestgrid.Response.Extensions.Validation.Sample/README.md) | Data annotations conversion to result messages and invalid results. |
| [Nestgrid.Response.AspNetCore.Sample](Nestgrid.Response.AspNetCore.Sample/README.md) | Minimal API result conversion with default and value-only responses. |
| [Nestgrid.Response.Mvc.Sample](Nestgrid.Response.Mvc.Sample/README.md) | MVC controller result conversion. |
